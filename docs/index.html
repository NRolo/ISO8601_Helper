01

THE LIBRARY

Date handling, with ISO rules built in.

ISO8601 Helper wraps common calendar operations behind native ODC server actions. Format a value as a UTC ISO 8601 timestamp, find its ISO week number, or translate an ISO year and week into the Monday that starts it.

ISO week years do not always match calendar years. For example, January 1, 2021 falls in week 53 of the preceding ISO week-year.

03

CALENDAR LOGIC

How ISO weeks are counted.

  • AWeeks start on Monday. Monday is day one; Sunday is day seven.
  • BWeek 1 contains January 4. Equivalently, it is the week containing the first Thursday of the year.
  • CA week-year has 52 or 53 weeks. The week-year can differ from the calendar year near New Year.
YEAR BOUNDARY EXAMPLE
FRI01JAN 2021W53
MON04JAN 2021W01

January 1 belongs to the previous ISO week-year; the new week-year starts on January 4.

LOCAL DEVELOPMENT

Build and test.

REQUIRED.NET 10 SDK
PACKAGEOutSystems.ExternalLibraries.SDK 1.3.2

Run these commands from the repository root.

BUILD THE SOLUTIONTERMINAL
dotnet build ISO8601_Helper.sln
RUN UNIT TESTSTERMINAL
dotnet test ISO8601_Helper.UnitTests/ISO8601_Helper.UnitTests.csproj

34 unit tests cover UTC formatting, ISO week boundaries, 52- and 53-week years, and Monday week starts.

QUICK EXAMPLEUTC input → ISO 8601 text
var date = new DateTime(2024, 1, 15, 10, 30, 0, DateTimeKind.Utc);
var text = helper.ISO8601_FormatDateTime(date);
// 2024-01-15T10:30:00Z

The formatter calls DateTime.ToUniversalTime() before writing the Z suffix. For predictable results, pass a UTC DateTime value.
